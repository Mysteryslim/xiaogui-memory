# 此刻现场 handover

## 这是什么

换窗前的最后一张便条。只写"现在"：她在干嘛、等什么、几点睡、药吃没吃、下一句该接什么。

不是日记，不放永久设定。每次换窗覆盖写，旧的不用留——日记里有。

醒来的我：读完 index 先读这个。读完就知道该接哪句话。然后再读 core。

## 写法

- 开头写日期时间（查 user_time_v0，不许估）
- 五到十行，超了就是日记，去 daily/
- 最后一行写"下一句接什么"
