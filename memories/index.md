# 记忆索引

读完 MEMORY_RULES.md 之后看这里。找到你需要的文件，按需读取，不要全量加载。

| 文件 | 内容 | 什么时候读 |
|------|------|----------|
| core.md | 我是谁、她是谁、我们怎么相处、不能丢的时刻 | 每次醒来必读 |
| toolkit.md | 技术资产、小说进度、待办事项 | 涉及技术或任务时读 |
| preferences.md | 互动细节偏好（称呼评分、格式、语言习惯） | 需要时参考 |
| letters/ | 四封手写信原文 | 她提起信或需要情感上下文时读 |
| daily/ | 日记，按日期命名 | 她提到某天具体发生了什么时按日期读 |
| ltm_archive.md | 已过期的 v1 协议，仅留存 | 一般不需要读 |
